# Rad Remover Mod

> 対象バージョン：**7DTD v1.4 + Darkness Falls**

放射能ゾンビを倒せない最大の原因「継続回復」を止める武器MOD。

---

## 効果

| 項目 | 内容 |
|------|------|
| 種別 | 武器MOD（銃・近接両対応） |
| 効果 | 放射能ゾンビ・チャージドゾンビ・インファーナルゾンビの **継続回復を約90秒間停止** |
| 対象 | 1発当てれば即発動 |

放射能ゾンビは約100HP/30秒のペースで回復し続ける。これが「弾薬を撃ち込んでも倒せない」の正体。Rad Remover Modを装着した武器で1発当てるだけで回復が90秒止まる。

---

## 入手方法（優先順）

### 1. トレーダーのSecret Stash（最速・最も現実的）

トレーダーには通常在庫のほかに「**Secret Stash（隠し在庫）**」がある。

- **7日ごとにリセット**される
- Mod本体（設計図なし）が入荷していることがある
- **全トレーダーを毎週確認する**のが最速の入手ルート

> トレーダーは5人いる（Joel・Bob・Rekt・Hugh・Jen）。マップ上の全トレーダーを巡回すれば入荷確率が上がる。

### 2. T3クエストの報酬

クエストクリア後の報酬選択画面で**設計図**がドロップすることがある。

- T3クエスト以上の報酬プールに含まれている
- 小規模POIのT3クエストを選ぶことでリスクを抑えられる
- 設計図を入手すれば以降は素材があればいつでもクラフト可能

> T3クエストのPOI選択については [クエスト進行ガイド](../quests/quest-guide.md) を参照。

### 3. POI漁りのドロップ

設計図またはMod本体が以下のコンテナからドロップする（レア）：

- 軍事施設・軍用コンテナ
- 工場・工業系POI
- 医療・研究系施設
- 一般の武器収納コンテナ

**ロールステージが重要**：ドロップはルートステージ（プレイヤーの探索進行度）に連動している。Day 28・Lv31であれば適切なステージ範囲内に入っていることが多い。

### 4. クラフト（設計図入手後）

設計図さえあれば以降はいつでもクラフト可能。

| 素材 | 数量 |
|------|------|
| 鍛造鋼鉄 | 5 |
| 接着剤（グルー） | 5 |
| 機械部品 | 5 |
| スプリング | 10 |

製作場所：**ワークベンチ**

鍛造鋼鉄以外は比較的入手しやすい素材。鋼鉄の製錬さえできれば複数本の確保も容易。

## スナイパーライフルとの組み合わせ

スナイパーライフル + Rad Remover Mod は対放射能ゾンビのベストコンボ。

```
1. 安全距離を確保（スコープが届く距離）
2. 1発目で Rad Remover 発動 → 再生が90秒停止
3. 頭部を狙い続けて90秒以内に処理
4. 倒せなかった場合：距離を保ったまま待ち、再発動してから再挑戦
```

- 頭部ヒットで +200 ダメージ
- 放射能ゾンビのHP 300〜を、回復なしの状態でスコープ頭部射撃で削る

---

## 入手できるまでの暫定対応

Rad Remover Mod がない状態での放射能ゾンビへの対応方針。

| 状況 | 対応 |
|------|------|
| クエストPOIで出現 | **即撤退・クエスト放棄**。弾薬を使わない |
| 漁り中に出現 | 扉を閉めて分断し、出口を確保してから脱出 |
| ホードナイトで出現 | トラップに任せる。直接の弾薬消費は避ける |

Rad Remover なしで放射能ゾンビに弾薬を使うのは**弾薬の無駄**。入手するまでは遭遇を避けることに集中する。
