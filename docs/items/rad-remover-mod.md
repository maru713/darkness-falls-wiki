# Rad Remover Mod

> 対象バージョン：**7DTD v1.4 + Darkness Falls**

放射能ゾンビの継続回復（100HP/30秒）を止める武器MOD。

---

## 効果

| 項目 | 内容 |
|------|------|
| 種別 | 武器MOD（銃・近接両対応） |
| 効果 | 放射能ゾンビ・チャージドゾンビ・インファーナルゾンビの **継続回復を約90秒間停止** |
| 発動 | 1発命中で即発動 |

---

## 入手難易度の現実

**入手方法はすべて運要素が高く、確実なルートは存在しない。**

| 方法 | 確実性 | 補足 |
|------|--------|------|
| トレーダー在庫 | **低〜不明** | Trader Stage（プレイヤーLv＋クエスト進行＋スキル）が不足だと在庫に並ばない可能性が高い |
| POI漁り | 低 | 軍・工場系コンテナからレアドロップ。放射能ゾンビがいるPOIに入る必要がある |
| T3クエスト報酬 | 低〜中 | T3クエストをクリアすれば設計図がドロップすることがある。ただしT3自体が放射能ゾンビだらけ |
| クラフト | **設計図が必要** | 設計図を入手できなければ作れない |

> **結論：Rad Remover Modはすぐに手に入るものではない。** 入手を待つ間は別の対策（後述）で凌ぐことになる。

## トレーダーについて

### バニラトレーダー（5人）
Joel・Bob・Rekt・Hugh・Jen。在庫は **Trader Stage** で決まる。

```
Trader Stage = プレイヤーLv × 1 + クエストティア + Daring Adventurerスキル × 10
```

Trader Stageが低い段階では Rad Remover Mod が在庫に出ない可能性が高い。

### Darkness Falls追加トレーダー：Caitlin（ケイトリン）
最強クラスの商品を扱うが**荒れ地（Wasteland）バイオームに住んでいる**。放射線耐性がないと近づけない。

## Rad Remover Modが入手できるまでの暫定対策

### スナイパーライフルによる距離管理

Rad Removerなしでも、**放射線デバフの範囲外から頭部射撃を繰り返す**ことで時間をかけて処理できる。ただし弾薬消費が激しく、再生に追いつかれることが多い。

- 回復量（100HP/30秒）より高いDPSを維持できるかが鍵
- スナイパーライフルの頭部ダメージ（+200）でどうにかなる場合もある
- 処理できそうになければ**撤退・クエスト放棄**を優先する

### 遭遇を回避する（最も安全）

放射能ゾンビがいることが確認できたら交戦しない。

- POI内で発見→扉を閉める→脱出
- クエストが達成不能と判断→放棄してリセット

---

## スナイパーライフルとの組み合わせ（入手後）

```
1. 安全距離（スコープが届く範囲）を確保する
2. 1発目で Rad Remover 発動 → 再生が90秒停止
3. 頭部を狙い続けて90秒以内に処理
4. 倒せなかった場合 → 距離を保ったまま再発動してから継続
```
