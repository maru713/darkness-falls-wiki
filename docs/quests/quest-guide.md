# クエスト進行ガイド（この世の地獄難易度）

> 放射能ゾンビによるクエスト失敗を避けるための、ティア・POI・バイオームの選び方。

---

## クエストティアと推奨装備

| ティア | 推奨時期 | 主な敵 | 必要装備水準 |
|--------|----------|--------|--------------|
| T1 | Day 1〜14 | 通常・腐ったゾンビ | 石器〜低品質鉄武器 |
| T2 | Day 7〜21 | 通常・フェラルゾンビ混在 | 中品質鉄装備 |
| T3 | Day 21〜 | フェラル・放射能ゾンビ混在 | 放射線耐性100%＋中品質鋼鉄装備 |
| T4 | Day 35〜 | 放射能・デモニックゾンビ | 上位装備・高スキル必須 |
| T5 | エンドゲーム | デモニック主体 | ゲーム最高品質装備 |

**ポイント：T3以降に放射能ゾンビが安定して出現する。放射線耐性なしでT3に入るのは自殺行為。**

---

## POI選択の基準

### 安全なクエストPOI（T1〜2で選ぶべき）

- 民家系（house_old_victorian等）
- ガソリンスタンド
- 小型商店・食料品店
- 農場・小屋

### 危険なクエストPOI（装備完成まで拒否推奨）

- 工場・製造施設
- 病院・医療施設
- 高層ビル・オフィス
- 警察署・刑務所
- 軍事施設
- **荒れ地バイオーム内の全POI**

### クエスト拒否のタイミング

トレーダーからクエストを受ける前に**POI名とバイオームを確認する**。危険なPOIへのクエストは迷わず拒否して次のクエストを選ぶ。拒否してもトレーダーランクのペナルティは軽微。

---

## バイオーム別リスク

| バイオーム | 放射能ゾンビ出現率 | 推奨時期 |
|-----------|-----------------|----------|
| 森 | 低 | 序盤から安全 |
| 雪原 | 低〜中 | 序盤から利用可 |
| 砂漠 | 中 | Day 14以降推奨 |
| 荒れ地 | **極めて高い（主力スポーン）** | **Day 21以降・放射線耐性100%必須** |

## クエスト中に放射能ゾンビと遭遇した場合

### 対処フローチャート

```
放射能ゾンビ発見
  │
  ├─ 放射線耐性100%ある？
  │    ├─ YES → 弾薬十分？
  │    │          ├─ YES → 正面突破（高火力武器で集中砲火）
  │    │          └─ NO  → 迂回ルートを探す / 近接で各個撃破
  │    └─ NO  → 即撤退・クエスト放棄
  │
  └─ 放射線デバフを受けた？
         ├─ YES → 脱出後にラジアションパルを使用
         └─ NO  → 距離を保ちながら処理継続
```

---

## 序盤の金策

クエストを繰り返すのが最も安定した金策。

- **T1クエスト × 多数回** がコスパ最大（リスクが低く、トレーダー信頼度も上がる）
- 信頼度が上がるとT2・T3のクエストに解禁ラインが下がり報酬も増える
- 探索と漁りで得たアイテムもトレーダーに売却して収入源にする
