# 放射能ゾンビ (Irradiated Zombie)

> **この世の地獄難易度における最大の序盤障害。** バニラクエストや漁りを妨げる根本原因を理解し、適切な目標を立てることが突破の鍵。

---

## ゾンビ強さ階層

Darkness Fallsのゾンビは明確な強さ段階があり、放射能ゾンビは上から2番目に位置する。

| 段階 | 種別 | 特徴 |
|------|------|------|
| 1 | 腐ったゾンビ | 最弱。序盤の基本敵 |
| 2 | 通常ゾンビ | 標準的な強さ |
| 3 | 狂暴化ゾンビ (Feral) | 昼間も走る。大幅に強化 |
| 4 | **放射能ゾンビ (Irradiated)** | **高HP・高ダメージ・継続回復・放射線デバフ付与** |
| 5 | デモニックゾンビ | 最強。ファイアボール投擲 |

各段階はおおよそ倍々で強くなる。放射能ゾンビは通常ゾンビの8倍前後の脅威度を持つ。

---

## なぜ序盤に問題になるのか

### バニラクエストへの影響

トレーダークエスト（クリア・漁り・復旧ミッション）のPOIには、**クエストティアに関わらず放射能ゾンビがスポーンする場合がある**。この世の地獄難易度ではゲームの難易度倍率が最大なので、序盤のゲームステージでも高ティアの敵が混入しやすい。

結果として：
- ティア1クエストのPOIで放射能ゾンビが出現
- 低品質の武器では弾薬が枯渇してクリア不能
- 放射線デバフで大幅にHP・スタミナが削られ逃走も困難

### 漁りへの影響

自由探索中の漁りも同様で、特に以下の状況で遭遇リスクが高い：

- **荒れ地バイオーム（Wasteland）** ― 完全なエンドゲームエリア。放射線100%、放射能ゾンビが主要スポーン
- **高層・大型POI** ― 建物規模が大きいほど上位ゾンビが混在
- **夜間探索** ― 全ゾンビが狂暴化し判断が困難に

---

## 目指すべき目標（段階的ロードマップ）

放射能ゾンビに対抗できるようになるまでのマイルストーン。

### フェーズ1：序盤（Day 1〜7）― 放射能ゾンビを避ける

**目標：接触しないことが最善策**

- [ ] バイオームを**森・雪原・砂漠に限定**する（荒れ地は絶対禁止）
- [ ] クエストは**ティア1〜2のみ**、小規模POI（家、ガソリンスタンド）を選ぶ
- [ ] 放射能ゾンビと遭遇したら**即撤退**。倒そうとしない
- [ ] 弾薬を温存する（ホードナイトで不用意に使い切らない）

### フェーズ2：中盤準備（Day 8〜21）― 対抗装備を整える

**目標：放射線耐性100%の達成**

- [ ] **テーラリングワークステーション**を設置する
- [ ] 「**放射線対応**」カスタムパーツを作成し、防具にセットする
  - 通常のハザマットスーツは防御力ゼロのため非推奨
  - 防具の防御力を維持したまま放射能耐性を積める
- [ ] 放射能耐性が100%になるまでパーツを複数スロットに装着
- [ ] 中品質の鉄装備か、クラス対応装備を揃える

### フェーズ3：対抗開始（Day 21〜）― 正面突破

**目標：放射能ゾンビを安定して倒せる火力の確保**

- [ ] ライフル・ショットガン等の中〜高ダメージ武器を入手
- [ ] スキルポイントを主要武器スキルに集中投資
- [ ] ティア3クエストに挑戦開始（POI規模が大きくなるため事前に装備確認）
- [ ] 荒れ地探索の解禁

---

## 具体的な対策

### 1. 放射線対応防具の作成（最優先）

テーラリングワークステーション → 「放射線対応」MODパーツ

- 防具の各部位（頭・胸・脚・足・手）にセット可能
- **合計で放射能耐性100%になれば放射線ダメージを完全遮断**
- 荒れ地バイオームの環境放射線にも有効

### 2. クラス選択による緩和

序盤のリソース不足を減らすことで、放射能ゾンビとの不意な遭遇によるリセットリスクを下げられる。

| クラス | 放射能ゾンビ対策への貢献 |
|--------|--------------------------|
| スカベンジャー | サバイバースキルLv3で食料・水を自給できる。長期探索の安定性が上がりリスク管理しやすい |
| ハンター | 弓・クロスボウのスニークアタック（ダメージ+100%）で放射能ゾンビを遠距離無音処理できる。ただし**ギリースーツMODと放射線対応MODは同時装着不可**という固有の制限がある |
| セキュリティ | 高耐久性と重装甲が特長。放射能ゾンビを受けるダメージを最小化 |

> **ハンター固有の注意**: ギリースーツ（ステルス強化）と放射線対応MODを同一防具に併用できないため、防具を2セット用意して使い分けることを推奨。詳細は [ハンター中盤ガイド](../early-game/hunter-midgame.md) を参照。

### 3. クエストPOIの選別

クエスト受注時に**POIの規模と種類**を確認する：

- 小屋・民家・ガソリンスタンド → 低リスク（推奨）
- 工場・病院・オフィスビル → 高リスク（中盤以降）
- 荒れ地エリアのクエスト → 装備完成まで拒否する

### 4. 武器MODによる再生無効化

放射能ゾンビが「弾を吸い込んでも倒せない」と感じる場合、ほぼ確実に**継続回復（100HP/30秒）**が原因。

| 武器MOD | 効果 |
|---------|------|
| **Rad Remover Mod** | 放射能ゾンビの再生を**約90秒間停止**。スナイパーライフル等に装着 |
| Blessed Metal Mod | アンデッド全般へのダメージ増加 |

Rad Remover Mod を装着した状態でまず1発当てると、90秒以内に残HPを削り切れる。入手はトレーダー購入またはPOI漁り。

### 5. 戦闘回避テクニック

- **近接特化のゾンビは狭い通路・ドアで渋滞させる** → 一体ずつ処理
- **高所から弓・クロスボウで削る** → 安全距離を確保
- 放射能ゾンビを発見したら**扉を閉めて分断し、音で誘導してから個別撃破**
- 放射線デバフを受けたら即座にその場を離れ、回復薬（ラジアションパル等）を使用

## よくある失敗パターン

| 失敗 | 原因 | 対策 |
|------|------|------|
| 弾薬を大量消費しても倒せない | 放射能ゾンビの継続回復が止まっていない | Rad Remover Mod を武器に装着する |
| 序盤クエストで弾切れ | 放射能ゾンビに弾薬を使いすぎた | 遭遇したら撤退、クエスト放棄も選択肢 |
| 荒れ地に踏み込んで即死 | バイオームの危険性を知らなかった | 放射線耐性100%達成まで立入禁止 |
| ハザマットスーツで防御ゼロ | 放射線対応=ハザマットと誤解 | テーラリングのMODパーツを防具に使う |
| ティア3クエストで全滅 | 火力・耐性が不十分 | Rad Remover + 放射線対応防具を揃えてから |
