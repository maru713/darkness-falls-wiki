# 序盤攻略ガイド（この世の地獄難易度）

> 放射能ゾンビが強すぎてクエスト・漁りが機能不全に陥るのが最大の壁。**最初の目標は「放射能ゾンビに遭わない環境を作ること」**。

---

## 最優先タスク（Day 1〜3）

### 食料・水の確保

- **スカベンジャークラス** → サバイバースキルLv3でピュアミネラルウォーターとジャーキーが作れる。序盤の食料・水問題を最速で解決できる
- Iron Gut（強い胃袋）パーク → 食料・水の消費速度が下がる。Day 1〜14で最も費用対効果が高いパーク

### 資材収集の優先順位

1. 家・ガソリンスタンドを中心に漁る（放射能ゾンビのスポーンが少ない）
2. 車を手当たり次第解体する（レンチで30〜50台が目安）
3. 鉄・石・砂を大量確保してオーガー解禁を目指す

### 絶対にやってはいけないこと

- **荒れ地バイオームへの侵入**（Day 21以降・装備完成まで禁止）
- 大型POI（工場・病院・軍施設）への序盤探索
- ホードナイトで弾薬を全消費する

## クラス選択

| クラス | 序盤メリット | 放射能問題への相性 |
|--------|-------------|------------------|
| スカベンジャー | 食料・水を自給、探索特化 | 長時間安全に漁りできる ◎ |
| ハンター | ブレード武器・肉解体量増加 | 消音近接で余計なゾンビを引かない ○ |
| 労働者 | 「時計」で時間管理が格段に楽 | 夜間の放射能ゾンビ凶暴化を回避しやすい ○ |
| セキュリティ | 重装甲・機関銃特化 | 正面突破向き、序盤は装備が整うまで不安定 △ |

## 漁りの安全ルール

### 安全なPOI（序盤推奨）

- 一般民家・小屋
- ガソリンスタンド
- 小型商店
- 農場

### 危険なPOI（中盤以降）

- 工場・倉庫
- 病院・クリニック
- オフィスビル・高層建築
- 警察署・軍施設
- **荒れ地エリアの全POI**

### 漁り中に放射能ゾンビを発見したら

1. **即座に扉を閉めて距離を取る**
2. 追いかけてくるようなら建物外へ撤退
3. クエスト中なら**クエストを放棄してリセット**（経験値は無駄になるが死亡より安い）
4. 弾薬が十分にある場合のみ、外から窓越しに処理する

---

## リソース管理

### 弾薬の原則

- 序盤は**ホードナイトでも最小限の弾薬**で済ませる
- 放射能ゾンビ1体に対して正面から弾を使い切るのは×
- 弾薬の補充が難しい間は、ダーツトラップ・ブレードトラップ・電気フェンスに頼る

### ベース設計の原則

- 生活拠点とホードベースは**別々に建設**する
  - ホードベースが壊滅しても生活拠点が無事
- 序盤のホードベースは「ゾンビに倒させるダメージを最小化」する迷路型が有効
- トラップ（ダーツ・ブレード・電気フェンス）を多層配置する

## 放射能耐性を整えるロードマップ

```
Day 1〜7   : 安全エリア限定で漁り・クエスト。放射能ゾンビは逃げる
Day 7〜14  : テーラリングワークステーション設置。放射線対応MODパーツ作成開始
Day 14〜21 : 防具に放射線対応パーツを装着。耐性100%を目指す
Day 21〜   : ティア3クエスト・荒れ地探索の段階的解禁
```
