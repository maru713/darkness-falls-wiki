## ハンター固有のジレンマ：ステルス vs 放射能耐性

### 制限事項（重要）

**ギリースーツMODと放射線対応MODは同じ防具に同時装着できない。**

これはDarkness Falls固有の設計制限。ハンターの最大の強みであるステルスと、放射能ゾンビ対策に必要な耐性装備が**直接競合する**。

### 2つの戦略ルート

| ルート | 内容 | 向いている人 |
|--------|------|------------|
| **A. ステルス回避型** | ギリースーツを維持。放射能ゾンビは倒さず、忍び込んで漁り・クエストを遂行 | 近接・接触を避けたい人 |
| **B. 放射能対応型** | ギリースーツを外し、放射線対応MODを装備。正面から対抗できるようにする | 安定したクリアを目指す人 |

> **推奨**: Day 28時点では**A（ステルス回避型）を主軸**に、**2セット目の装備としてB（放射能対応型）を並行構築**する。状況で使い分けるのが最も柔軟。

---

## ルートA：ステルス回避型（即座に実践可能）

### ハンターの対放射能ゾンビ戦法

ハンターのスニークアタックは**ダメージ+100%ボーナス**が入る。これを活用すれば、放射能ゾンビを「倒す」のではなく「安全に無力化」できる。

#### 実践手順

1. **ギリースーツMOD装着状態でPOIに忍び込む**
2. **放射能ゾンビの背後にスニーク接近**
3. **コンパウンドクロスボウ/ボウで頭部スニークアタック**
   - ダメージ2倍×頭部倍率で大ダメージ
   - 無音なので他のゾンビを引き寄せない
4. **1〜2発で倒せない場合は距離を取り、再スニーク**
5. **放射線デバフに注意** → デバフが入ったら即エリア離脱

#### 注意点

- 放射線デバフは近距離での被弾時に発生しやすい
- **接近戦（ブレード）は危険**：放射線デバフをもらいやすく、ハンターの防御力では致命傷になる
- 複数同時に相手にしない。必ず1体ずつ処理する

### POI内での動き方

```
入口でスニークモード開始
  │
  ├─ 通常ゾンビ → スニークアタックで静かに処理
  │
  ├─ フェラルゾンビ → スニークアタック2〜3発、または迂回
  │
  └─ 放射能ゾンビ発見
         ├─ 背後が取れる → スニーク頭部クロスボウで挑戦
         └─ 背後が取れない → 扉で分断して迂回、または撤退
```

## ルートB：放射能対応型（並行構築）

### テーラリングワークステーションの設置

**これが最優先の設備投資**。まだ設置していない場合は即対応。

- テーラリングワークステーション → 「放射線対応」MODパーツをクラフト
- 防具の各部位に装着し、放射能耐性の合計を100%にする
- ギリースーツMODとは併用不可なので、**防具を2セット用意する**

#### 2セット運用例

| セット | 装備内容 | 使用場面 |
|--------|---------|---------|
| ステルスセット | ギリースーツMOD装着 | 安全エリアのクエスト・漁り |
| 放射能対応セット | 放射線対応MOD×必要数 | 荒れ地・高難度POI・T3クエスト |

## ハンタースキル投資の優先順位

Level 31前後で残りポイントをどこに使うか。

| 優先度 | スキル/パーク | 理由 |
|--------|------------|------|
| 最高 | 弓/クロスボウ マスタリー | スニークアタックの威力倍率に直結 |
| 高 | スニーク | 発見されにくくなり、放射能ゾンビへの接近が容易に |

| 中 | Ranger系スキル | 射程・精度向上 |
| 低（後回し） | ブレード系 | 放射能ゾンビへの近接は危険なため当面封印 |

## まとめ：Day 28ハンターの優先行動

1. **コンパウンドクロスボウ入手** → スニーク頭部ワンパンを狙える火力を確保
2. **テーラリング設置 → 放射線対応MOD作成** → 2セット目の防具完成
3. **T2クエストをステルスで高回転** → 装備・弾薬・資金を積む
4. **T3クエストは小規模POI限定で慎重に開始**

放射能ゾンビを「正面から全員倒す」のではなく、**「スニークで無力化または回避しながらクエスト・漁りを遂行する」**のがハンターの正解ルート。
