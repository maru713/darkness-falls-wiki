# ハンタークラスのステルス効果

> 対象バージョン：**7DTD v1.4 + Darkness Falls V6系（⚠️ MOD正確なサブバージョンは各自確認）**

> **情報の信頼度**：✅ ステルスの基本仕組み / ⚠️ DF固有の数値・クエスト中の有効性

---

## ステルス効果の3本柱

| 効果 | 内容 |
|------|------|
| **スニーク移動速度向上** | スニーク歩きがスニークダッシュと同速度になる。他クラスより素早く隠密移動できる |
| **スニークアタックダメージ増加** | スニーク中の攻撃に倍率がかかる。バニラ基礎1.5倍〜スキル最大4倍（⚠️ DF固有倍率は未確認） |
| **騒音生成量の軽減** | 移動・動作時の騒音が他クラスより少ない。ゾンビに気づかれにくい |

---

## ステルスの基本メカニクス（7DTD）

### 検知に影響する要因

| 要因 | 内容 |
|------|------|
| 光レベル | 明るい場所では発見されやすい |
| 騒音 | 移動・扉の開閉・武器使用で騒音が発生 |
| 距離 | 近づくほど発見されやすい |
| 視野 | ゾンビの視野は30ブロック・180度 |

### ステルスメーター

画面左下に表示される。**数値が低いほどステルス状態が良い**。

### ゾンビが騒音に気づいた場合の挙動

- 最後に音がした場所へ移動する
- プレイヤーを直接追跡するわけではない
- 数歩横にずれるだけでロストすることも多い

## クエスト中のステルスの限界

### POIのスリーパーボリューム（強制起動）

7DTDのPOIには**スリーパーボリューム**というトリガーエリアが設定されている。

- 特定の扉・部屋・エリアに踏み込むと、**ステルス状態に関わらずゾンビが起動する**
- クエストをアクティブにした状態では、この強制起動が発生しやすい
- 「ゾンビが起動する ≠ 即座に発見される」ではあるが、ステルスが崩れるリスクが上がる

### 現実的な評価

| 状況 | ステルスの有効性 |
|------|---------------|
| 野外・廃屋の漁り | **有効**。騒音・光の管理で長時間ステルス維持できる |
| 小規模POIのフェッチクエスト | **部分的に有効**。スリーパー起動トリガーがある部屋は突破できないことがある（⚠️ 有効性の度合いは未定量） |
| 大型POI・クリアクエスト | **ほぼ機能しない**。スリーパートリガーが多く強制戦闘が多発する |

**「ハンターのステルスでフェッチクエストを完全安全に遂行できる」とは言えない。リスクを下げる手段として機能するが、確実な回避保証はない。**

---

## 実戦でのステルス活用

### 効果的な場面

- POI入場前に周囲の音を確認する時間を取る
- スニーク状態でゆっくり進み、ゾンビとの距離を把握する
- 起動したゾンビをスニーク状態のまま扉で分断する

### 限界を認識すべき場面

- トリガーが発動して複数のゾンビが起動した場合 → 脱出を優先
- 複数フロアの大型POI → 強制起動が連鎖する
- クリアクエスト → 全ゾンビ討伐必須なのでステルス回避の意味がない
