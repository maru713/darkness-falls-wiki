## この世の地獄難易度とは

Darkness Falls MODをゲーム内最高難易度「この世の地獄」で遊ぶ設定。ゾンビの強さ・スポーン数が最大倍率となり、**序盤から放射能ゾンビが通常クエストPOIや一般エリアに出現する**ことが最大の特徴にして最大の障壁。

### 最重要課題

> **放射能ゾンビが強すぎてバニラクエストと漁りが機能しない**

この問題の根本原因と解決ロードマップは [放射能ゾンビのページ](docs/zombies/radioactive-zombie.md) を参照。
